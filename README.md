## Overview

Maag Audio EQ4 MS is a Windows audio plugin created for mastering-centric equalization inside a DAW. It mirrors the Mäag Audio EQ4 MS in digital form and focuses on giving engineers practical tonal control with modern plugin workflow support.

It is intended for mix and mastering tasks where exact stereo and spectral shaping matters. With mid-side processing, air band adjustment, and filter controls, it lets you fine-tune the center and sides of a source without building extra routing steps.

## Using the Plugin

1. Open your DAW and load Maag Audio EQ4 MS on a track, bus, or master chain.
2. Choose whether you want standard stereo processing or mid-side adjustment.
3. Use the air band shelf to add or refine top-end presence.
4. Shape the low end with shelving or peaking controls as needed.
5. Engage the high-pass filter when cleaning up unwanted low frequencies.
6. Save the setting as part of your project so recall and automation remain available.

Example workflow:

- Insert on a mix bus for broad tonal shaping
- Switch to mid-side mode for focused stereo adjustments
- Automate EQ moves across different song sections
- Return to the saved state instantly during mix revisions
